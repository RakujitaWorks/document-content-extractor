# Document Content Extractor

Document Content Extractorは、Word・Excel・PowerPointファイルから画像、テキスト、埋め込みデータを抽出し、ZIPにまとめるブラウザツールです。

Version 1.0.0

ファイルの解析とZIP生成はブラウザ内で行われ、選択したファイルを外部サーバーへ送信しません。

## Web版

[Document Content Extractorをブラウザで開く](https://rakujitaworks.github.io/document-content-extractor/)

## 表示言語

画面表示は日本語と英語に対応しています。

ページを開いた時点で、ブラウザの優先言語が日本語の場合は日本語、それ以外の場合は英語で表示されます。画面上の言語切替から、ページを再読み込みせずに表示言語を変更できます。

選択した言語は保存されません。ページを再読み込みすると、ブラウザ言語から再度判定されます。

## 主な特徴

- Word・Excel・PowerPointの新旧Office形式に対応
- 画像・音声・動画などのメディアを元データのまま抽出
- 文書、セル、図形、表、ノートなどのテキストを抽出
- OLEなどの埋め込みデータを抽出
- 複数ファイルやフォルダをまとめて処理
- 抽出結果を1つのZIPファイルとして保存
- インストール不要
- 外部サーバーへのアップロードなし
- 第三者ライブラリ不使用

## 対応形式

| アプリ | 新しいOffice形式 | Office 97～2003形式 |
| --- | --- | --- |
| Word | `.docx`、`.docm` | `.doc` |
| Excel | `.xlsx`、`.xlsm`、`.xltx`、`.xltm` | `.xls`（BIFF8） |
| PowerPoint | `.pptx`、`.pptm`、`.potx`、`.potm` | `.ppt` |

拡張子だけではなく、ファイル内部の形式も確認します。拡張子と内部形式が一致しないファイル、暗号化・パスワード保護されたファイル、Office 95以前の形式、RTF、PDF、OpenDocumentなどは処理対象外です。

## 抽出できる内容

### メディア

- 文書内の画像
- 音声
- 動画
- OfficeArt内の画像データ

メディアは再保存、再圧縮、再エンコード、形式変換を行わず、取得できた元データをそのまま出力します。

### テキスト

- Wordの本文、表、ヘッダー、フッター、脚注、文末脚注、コメント
- Wordの図形・テキストボックス・WordArt・グラフ内テキスト
- Wordの標準ルビと一部の旧式ルビ
- Excelのセル、保存済み計算結果、図形・テキストボックス内テキスト
- PowerPointのスライド、図形、表、発表者ノート

取得できる位置情報を使用し、可能な範囲で見た目に近い順序へ並べて出力します。

### 埋め込みデータ

- OOXML形式の `embeddings` 内データ
- 旧Office形式のOLE埋め込みデータ

埋め込みデータは安全のため実行・プレビューしません。抽出後のファイルは、内容を確認してから取り扱ってください。

## 使い方

1. GitHub Pages版または単一HTML版を、Google ChromeまたはMicrosoft Edgeで開きます。
2. フォルダを追加する場合は、先に「フォルダ追加時にサブフォルダも読み込む」を設定します。
3. 「ファイルを追加」または「フォルダを追加」で対象を選択します。
4. 必要に応じて、テキスト抽出と埋め込みデータ抽出を設定します。
5. 一覧の判定状態が「処理対象」になったことを確認します。
6. 「全件をZIPで書き出す」を押します。
7. 抽出結果のZIPファイルを保存します。

ファイルやフォルダを画面へドラッグ＆ドロップして追加することもできます。

フォルダ追加後にサブフォルダ設定を変更しても、追加済みの一覧には遡って反映されません。設定を変えて読み込み直す場合は、対象を一覧から削除してから再追加してください。

一覧のチェックボックスは、「選択した項目を削除」で一覧から外す項目を選ぶために使用します。ZIP書き出しでは、チェック状態に関係なく、一覧内の処理可能な全ファイルが対象になります。

## 単一HTML版

`standalone/document_content_extractor.html` は、CSSやJavaScriptを1ファイルへまとめた単一HTML版です。

ファイルをダウンロードし、Google ChromeまたはMicrosoft Edgeで直接開くことで、Webサーバーを使用せずに実行できます。Officeファイルの処理にインターネット接続は必要ありません。

## 出力構成

入力ファイルごとにフォルダを作成し、抽出内容を次のように保存します。

```text
ZIP/
└─ 固定変換した相対親/（相対親がある場合）
   └─ 正規化したOfficeファイル名/
      ├─ 正規化したOfficeファイル名_text.txt
      ├─ media/
      │  ├─ Office名接頭辞_画像名.png
      │  └─ Office名接頭辞_画像名.jpg
      └─ embeddings/
         └─ 埋め込みファイル
```

相対親がない場合は、正規化したOfficeファイル名のフォルダをZIP直下へ作成します。

実際のファイル名は、Windowsで安全に扱えるように正規化されます。

- 半角スペースと全角スペースをアンダースコアへ変換
- 丸数字、全角英数字、半角カタカナなどをUnicode NFKCで正規化
- `髙` を `高` へ変換
- Windowsで使用できない文字を安全な文字へ変換
- Windows予約名を先頭のアンダースコアで回避
- 長すぎるファイル名やパスを安全に短縮
- 同名ファイルには連番を付加

テキストはOfficeファイル別フォルダの直下へ `<正規化したOfficeファイル名>_text.txt` の形式で出力し、UTF-8（BOMなし）、改行コードCRLFで保存します。抽出結果がない空ファイルや空フォルダは作成しません。

## 対応環境

- Windows 10 / Windows 11
- Google Chrome 現行安定版
- Microsoft Edge 現行安定版

FirefoxとSafariは必須対応外です。

OOXML形式の展開には、Chrome・Edgeの標準Web APIである `DecompressionStream` を使用します。非対応ブラウザでは、新しいOffice形式を処理できない場合があります。

## プライバシーとセキュリティ

- Officeファイルは外部サーバーへ送信しません。
- 処理は現在開いているブラウザタブ内で完結します。
- 外部API、テレメトリ、アクセス解析は使用しません。
- 入力ファイルは読み取り専用で扱います。
- マクロ、ActiveX、埋め込みファイル、外部リンクを実行しません。
- HTML形式の埋め込み内容を現在のページへ表示しません。
- XML内の危険な宣言を検出した場合は解析対象から除外します。

本ツールはOfficeファイル内のデータを抽出するものであり、ファイルの安全性を保証するものではありません。抽出した埋め込みファイルは、信頼できないファイルとして取り扱ってください。

## 制限事項

- 暗号化・パスワード保護ファイルは処理できません。
- 画像内の文字はOCRしません。
- 数式やグラフの値を再計算しません。
- Wordの自動改ページ、段組み、文字回り込み、重なり順を完全には再現しません。
- Excelの可変列幅、行高、図形の重なり、回転を完全には再現しません。
- PowerPointの複雑な重なり、回転、レイアウトを完全には再現しません。
- 旧Office形式はファイル構造の違いが大きいため、すべてのファイルで完全な抽出を保証するものではありません。
- 大容量ファイルは、ブラウザで利用できるメモリ量によって処理できない場合があります。
- ZIP64形式と分割ZIPには対応していません。

安全上限として、入力1件256 MiB、入力合計512 MiB、出力データ合計512 MiBなどの制限を設けています。上限を超えた場合は、不完全なZIPを保存せず処理を中止します。

## エラー発生時の動作

処理は入力ファイルごとに順番に実行します。

一部のメディアや埋め込みデータが破損している場合は、該当データだけを読み飛ばし、取得できた他の結果を可能な範囲で維持します。警告やエラーの内容は画面の処理ログに表示されます。

処理中は「処理を中止」を押せます。中止した場合、ZIPは保存せず、再実行できる状態へ戻ります。

## 第三者ライブラリ

第三者ライブラリは使用していません。

ZIP、CFB、OOXML、Word Binary File Format、BIFF8、PowerPoint Binary File Format、OfficeArtの解析と出力ZIPの生成は、プロジェクト内のJavaScriptで行います。
